##  Overview
This repository showcases a curated collection of **Kaggle competition-style projects** implemented using **Machine Learning** and **Deep Learning** techniques. Each notebook addresses real-world problems with clear, reproducible solutions.

Projects include:
- Iris flower classification (logsitic regression, decision tree)
- Ocean temperature prediction (time-series forecasting)
- Rainfall prediction (regression & tree-based models)
- Rossman store sales forecasting (with gradient boosting)
- NYC taxi fare estimation
- Car insurance claim prediction
- Weather temperature analysis

---

##  Structure
Each project is contained in its own Jupyter Notebook, featuring:
- **Problem Statement**
- **Data Loading & Exploration**
- **Modeling Methodology** (feature engineering, model training, and evaluation)
- **Insights & Next Steps**
